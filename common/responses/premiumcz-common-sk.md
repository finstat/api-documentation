##### Spoločné detail parametre:
| Parameter | Popis |
| ----------- | ----------- |
| **CzNaceCode** | CZ Nace kód – môže byť prázdny. Na `cz.finstat.sk` je vo Free, Detail a PremiumCZ dočasne, do vydania nového CZ API, kód tak, ako je uložený (napr. `43342`) |
| **CzNaceText** | CZ Nace popis – môže byť prázdny. Na `cz.finstat.sk` sú vo Free, Detail a PremiumCZ dočasne, do vydania nového CZ API, popisy CZ NACE po česky |
| **CzNaceDivision** | divízia CZ Nace – môže byť prázdna |
| **CzNaceGroup** | skupina CZ Nace – môže byť prázdna |
| **LegalForm** | právna forma popis - môže byť prázdny. Na `cz.finstat.sk` je vo Free, Detail a PremiumCZ dočasne, do vydania nového CZ API, po česky |
| **OwnershipType** | druh vlastníctva popis - môže byť prázdny. Na `cz.finstat.sk` je vo Free, Detail a PremiumCZ dočasne, do vydania nového CZ API, po česky |
| **Activity** | odvetvie podľa FinStat kategorizácie - može byť prázdne |
| **Warning** | príznak, či má subjekt v insolvenčnom registri (ISIR) konanie, ktoré nie je ukončené (stav iný ako `PRAVOMOCNA`, `ODSKRTNUTA` alebo `MYLNÝ ZÁP.`) (`true/false`) |
| **WarningUrl** | odkaz na záložku insolvenčného registra, vyplnený podľa rovnakej logiky ako `Warning` – môže byť prázdny |
| **EmployeeCount** | kategória počtu zamestnancov ako text v jazyku odpovede (napr. `10 - 19 zaměstnanců`, `Neuvedeno`) – môže byť prázdny |
