#### VehicleFleetItem
Položky rozpadov s počtom 0 sa nevracajú.

| Parameter | Popis |
| ----------- | ----------- |
| **Type** | typ položky podľa rozpadu (pozri `VehicleFleet`) |
| **Count** | počet vozidiel |

#### VehicleFleetBrand
| Parameter | Popis |
| ----------- | ----------- |
| **Name** | značka (napr. `ŠKODA`) alebo `Other` |
| **Count** | počet vozidiel |
